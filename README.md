# App193 — Painel Web

Painel web do **App193**, sistema de acionamento de emergências do Corpo de
Bombeiros Militar de Campo Verde. Permite à guarnição visualizar, atender e
despachar as ocorrências registradas pelos cidadãos no aplicativo mobile.

🔗 **Demo:** https://app-cbm-web.vercel.app

> **Acesso de teste:** `usuario@demo.com` / `demo123`

## Stack

React · Expo Web · JavaScript · Deploy na Vercel

## Projeto completo

Este repositório é uma das três camadas do sistema:

| Camada | Repositório |
